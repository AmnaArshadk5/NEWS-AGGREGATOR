# News Aggregator

A full-stack news aggregation app with a React frontend and a Node.js/Express backend.

## Features
- Browse news articles
- User authentication
- Save bookmarks
- Responsive UI

## Tech Stack
- Frontend: React, Vite, CSS
- Backend: Node.js, Express
- Data: JSON-based mock data

## Project Structure
- `frontend/` - React app
- `backend/` - Express server and API routes

## Getting Started

### Backend
```bash
cd backend
npm install
node server.js
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

## Notes
- Make sure the backend is running before using the frontend.
- This project is intended for local development and demonstration purposes.
